# CamWatermark

A privacy-first, browser-based photo styling studio for Nikon photographers.

## Features

- Local JPEG and PNG upload with drag-and-drop support
- Live colour-grade presets: clean, cinematic, amber film, moody, teal & orange, monochrome, and vibrant
- Customizable camera-brand watermark treatments
- Editable brand name, photographer name, font, position, opacity, size, spacing, and effects
- Client-side export to JPEG, with no image upload to a server

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static web server.

RAW `.NEF` support is intentionally deferred for a future release.

## Note on brand treatments

The app uses text and original CSS/SVG-style treatments rather than reproducing protected camera-company logo artwork. Use brand assets only when you have the appropriate rights.
